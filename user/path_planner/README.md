# 路径规划与控制模块使用手册(path_planner)

> 适用:抬升分支 STM32H723 工程 `user/path_planner/`
> 本文档描述**跑曲线全流程**:整体框架、每一步怎么算、每个细节怎么处理、如何使用、出错怎么排查。
> 代码与文档不一致时,以 `path_config.h` / `path_main.c` 为准。

---

## 1. 文件结构

| 文件 | 内容 | 谁来改 |
|---|---|---|
| `path_config.h` | **全部参数**(场地/墙/路点/速度/控制器/换算系数) | 调参只改这里 |
| `path_main.h` | 类型定义与对外接口声明 | 一般不改 |
| `path_main.c` | 全部算法实现(几何/样条/速度剖面/融合/纯追踪/总控) | 算法维护 |
| `map_check.py` | PC 端地图可视化与几何核对工具 | 运行 `python3 map_check.py` |

工程接线(已接好,勿动):
- `Core/Src/freertos.c` → `commTask` 内 `PathRunner_Init()` / `PathRunner_Run()`(1ms 调用,内部 5ms 分频);
- `Core/Src/main.c` → 串口回调挂 `PcLink_RxCplt/Error`;
- `user/com_link/computer_link.c` → `__weak PathPlanner_OwnsChassis()` 手动指令仲裁;
- `user/chassis_vesc/chassis_main.c` → `Chassis_StopAll` 刹车锁存(SET_BRAKE);
- `user/pc_link/` → 小电脑 0x10/0x11 帧解析与 0x20 状态帧回传(UART7, 115200)。

## 2. 系统总览

### 2.1 数据流

```
小电脑位姿 0x11 帧(50Hz) ── UART7 ── pc_link ──┐
IMU 陀螺/偏航(≈100Hz)  ─── USART1 ─ imu_main ──┤
前/左激光 DT35(50Hz) ──── UART9 ─ dt35_pnp ────┤
                                                ├──> 融合(fusion)
                                                │       ↓ 融合位姿(x,y,yaw)
                                                ├──> 查表(v_ref)+ 纯追踪(目标点)
                                                ├──> 前激光兜底 + 左激光微调
                                                ├──> yaw-lock + slew 限幅
                                                ↓
                        Chassis_SetVelocity(vx右, vy前, ω逆时针)
                                ↓ 每 10ms
                         FDCAN1 → 4×VESC(SET_RPM / SET_BRAKE)
反向:每 50ms 回小电脑 0x20 状态帧(55 AA 20 state error chk 0D 0A)
```

### 2.2 状态机

```
INIT(0) → CALIB(1) → WAIT_START(2) → BUILD(3) → RUN(4) → ARRIVED(5)
  任意状态 ──故障──> STOPPED(6)   (刹车锁存;终态停一次后手动可接管)
```

### 2.3 上电时间线(标称)

| 时刻 | 事件 |
|---|---|
| 0 | 外设初始化,commTask 启动 PathRunner → INIT(关 IMU 自带航向保持) |
| ~0.2s | UART7 开始有位置帧、UART9 有 DT35 帧(此阶段规划器不消费) |
| ~4.4–4.6s | IMU 自身标定/配置完成 → `IMU_STATE_READY` |
| 随后 ~1s | CALIB:采 200 帧陀螺求零偏(每 5ms 一帧) |
| CALIB 结束 | → WAIT_START |
| 收到首帧有效位姿 | 校验(数值/场内/\|yaw\|≤30°)→ 覆盖路点起点 → BUILD |
| 几十 ms | BUILD:样条 + 速度剖面 + 验收通过 → RUN |
| ~8–14s | 跟踪行驶 → 距终点 0.15m 内 → ARRIVED(刹车) |

## 3. 坐标系约定(最容易错的部分,必读)

| 系 | 定义 |
|---|---|
| **世界系** | 原点场地左下角,`+x` 向右(东),`+y` 向前(北) |
| **用户 yaw** | 上电清零;`yaw=0` = 车头朝 +y;逆时针为正 |
| **车体系** | `+x` = 车头正前(= +y 当 yaw=0),`+y` = 车体正左 |
| **底盘系** | `Chassis_SetVelocity` 的参数:`x`=向右平移、`y`=向前、`z`=逆时针 |

关键换算(世界→底盘直接用 `R(yaw)`,**不要**用 `R(yaw+π/2)`;后者是车体系):

```
底盘单位换算(已与仓库底盘解算闭合):
  轮半径 r = 0.050 m(底盘分支 odom_fusion.h)
  轴距 0.35 / 轮距 0.33(chassis_main.c CHASSIS_ROTATION_SCALE=3.5+3.30=6.8)
  PATH_RPM_PER_M_S = 60/(2πr) = 190.99        → rpm = v(m/s) × 190.99
  PATH_Z_PER_RAD_S = 60/(2π)   = 9.549        → z    = ω(rad/s) × 9.549
  chassis_main 内部 rotation_rpm = z × 6.8(与上面两式三值闭合)
```

`PATH_GYRO_SIGN=1.0`:若实车 gyro_z 符号反了(车左转读数却为正),yaw-lock 会变**正反馈原地打转**——上电前必须先验证(见 §8.4)。

## 4. 算法详解

### 4.1 位姿融合(互补滤波,非 EKF)

输入:IMU `gyro_z`(deg/s,已过 IMU 自身零偏修正)、小电脑位姿 `(x,y,yaw_rad)` 50Hz。
输出:融合 `(x, y, yaw)`。**控制只信融合值,永远不用原始值。**

每 5ms 控制周期:
1. **yaw 预测**:`yaw += (gyro_z + 附加零偏) × PATH_GYRO_SIGN × dt`(上电 CALIB 采 200 帧求的附加零偏);
2. **位置前馈(关键)**:上一周期下发的底盘指令速度 `(vx_c, vy_c)` 经 `R(-yaw)` 转到世界系,`x += vx_w·dt`。**位姿帧暂停期间估计值持续推进**,避免"估计冻结→恢复后正确帧被门限永久拒绝"的死锁;
3. **位姿校正**(仅在新帧到达时,按位置帧序号去重):
   - 首帧:`yaw` **全量初始化**;
   - 数值/场地范围校验(NaN、x∈[-0.5,3.5]、y∈[-0.5,6.5]);
   - **xy 门限 15cm**:与估计值差 >15cm 整帧拒绝(20cm/40cm 阶跃必拒);
   - **yaw 门限 20°**:超限只拒 yaw 分量;通过则 `yaw += 0.15×wrap(yaw_u−yaw)`;
   - xy 直接覆盖;
4. **重新捕获**:距上次被接受帧 >300ms(数据过旧)时,跳过 xy 门限直接接受新帧——前馈有误差(打滑)时不会永久拒绝。

**时效管理(两组时钟,语义不同)**:

| 时钟 | 刷新条件 | 超时动作 |
|---|---|---|
| 链路存活 `last_upper_ms` | 任何 CRC 有效帧 | >500ms → STOP_UPPER_LOST |
| 数据可用 `last_data_ms` | 通过门限的帧 | >100ms → 限速 0.3m/s;>800ms → 定位不可用停机 |

### 4.2 轨迹构建(BUILD,离线一次性)

1. **路点**:起点 = 小电脑实测位姿;`wp[1]/wp[2]` 按起点位置三分支动态生成
   (y≥1.12 垂直并入通道1 / x≤0.8 用 L 形 / 其余先西行 x=0.5 再北上);
   其余为 D 角圆弧(每 15° 采样点)与通道/缺口路点,见 `PATH_WAYPOINTS_TABLE`。
2. **B 样条**:3 阶、clamped、弦长参数化、de Boor 递推、300 点采样;
   首尾端点严格保留(= 起点/目标点)。
3. **离墙推离**:点落入**软膨胀墙**(半宽 0.26 / 半长 0.3485)时沿最小穿透轴推出;
   平滑轮数 = 0(密集弧点路点下样条已紧贴圆弧,平滑会把弧拉向弦线)。
4. **弧长 s 与曲率 κ = dθ/ds**(中心差分 + 3 点平滑)。
5. **速度剖面**(见 4.3)。
6. **轨迹验收**(见 4.4),最多重建 3 次,不过 → STOP_BUILD(不动车)。

### 4.3 速度剖面(离线)

对每个采样点:
1. **曲率限速(带 0.8m 弧长前视窗)**:`v_i = min(1.5, √(1.5 / κ_eff))`,
   `κ_eff` = 前方 0.8m 内最大 |κ|——**进弯前 0.8m 就开始减速**,给命令减速留 0.3m 余量;
2. **前向扫描(加速)**:`v²_{i+1} ≤ v²_i + 2×1.2×Δs`;
3. **反向扫描(刹车,用跟踪斜率)**:`v²_i ≤ v²_{i+1} + 2×1.6×Δs`
   (1.6 = 指令 slew 能力 2.0 × 0.8 安全系数,保证减速跟得上);
4. `v_min=0.2`(除终点外,防起步死锁);终点 `v_goal=0.3`;最终再按曲率封顶。

同时离线计算**期望激光表**:每点前/左射线投射(`PathGridMap_RayCast`,与运行同源几何)。
- `exp_laser_front_m`:前激光期望距离 → **期望墙门控**用(4.5);
- `exp_laser_left_m`:左激光期望距离 → 横向微调用(仅当 ≤0.2m 时启用)。

### 4.4 轨迹验收(进 RUN 前强制)

对**硬膨胀墙**(真实外廓半宽 0.235 / 半长 0.3235 + 1.5cm 余量):
- 每点净距 ≥ 0.02m;相邻线段中点穿透 ≤ 2mm(弦线切角容差);
- 采样间距 ≤ 0.15m;`|κ| ≤ 50`;`v²|κ| ≤ 1.8`(横加容差 1.2×);
- 数值合法性(NaN 即拒)。

### 4.5 在线控制(RUN,每 5ms)

1. **读传感器 + 融合**(4.1);
2. **安全前置检查**(顺序即优先级):
   位姿(从未收到/链路超时/数据过旧)→ IMU 离线 → 前激光离线 → 电机离线 → 20s 超时 → NaN;
3. **最近点查表**:前向窗口 150 点 + 回退窗口 10 点(防过冲卡死);
4. **纯追踪目标点**:`Ld = 0.08 + 0.06·v`,再用**前方 15 点窗口内最大曲率**限幅
   `Ld ≤ 0.08/√(κ_max+0.05)`——直角弯前就能看到急弯,不抄近道;
   世界系速度矢量 `v·(target−pose)/|·|`;
5. **前激光兜底(期望墙门控)**:
   - 读数 ≥ 0.20m(饱和)= 量程内无障碍 → 不约束;
   - **期望墙在量程内且读数 ≥ 期望−0.05m** → 位置正常,不减速
     (通道1 贴墙横移段,消除饱和边界噪声抖动);
   - 12cm < 读数 < 上限 → `v = √(2×1.8×(d−0.12))`;
   - 读数 ≤ 12cm:目标横向且是期望墙 → **0.25m/s 沿路径缓行回中**
     (方向由纯追踪目标给出,非盲侧移);否则完全停车,障碍消失自动恢复;
6. **左激光横向微调**:`err = laser_l − exp_l`,`vx_c += −1.5×err`(钳 ±0.3;
   左墙 <10cm 强制 +0.3 向右);仅当 `exp_l ≤ 0.2m` 启用;
7. **yaw-lock**:目标 0(车头 +y),死区 ±1°,|e|≤5° 用 Kp=1.5、否则 3.0,
   限幅 `w_max = max(0.3, 3.0 − 1.2×v)`;
8. **slew 限幅**:平移用**矢量幅值**限幅 `|Δv| ≤ 2.0×dt`(方向可自由转,
   逐轴限幅会扭曲转向,是历史撞墙的根因);旋转 `|Δw| ≤ 4.0×dt`;
9. 输出:`rpm_x = vx×190.99`,`rpm_y = vy×190.99`,`z = w×9.549`
   → `Chassis_SetVelocity`。

### 4.6 指令仲裁与停机

- RUN 期间 `PathPlanner_OwnsChassis()=true`,computer_link 丢弃手动速度/动作帧;
- 所有停机(含 ARRIVED)走 `Chassis_StopAll` → **VESC SET_BRAKE 18A 锁存**,
  chassisTask 每 10ms 重发保持制动;`Chassis_SetVelocity` 解除锁存;
- ARRIVED/STOPPED 只在进入时停一次,之后**手动指令可接管**(不用断电挪车)。

## 6. 使用指南

### 6.1 编译烧录

1. Keil 打开 `MDK-ARM/b-up.uvprojx`(文件已入库,`Application/User/path_planner` 分组);
2. 直接编译烧录(工程含 pc_link、path_planner,路径已配好);
3. **改参数只改 `path_config.h`,重编译即可**;改完建议先在 PC 跑一遍 §6.3 的 map_check。

### 6.2 上电前检查(实车契约,全部确认过再上电)

- [ ] 车头朝 +y(上电清零方向),起步 |yaw|≤30°;
- [ ] **gyro_z 符号**:手推车左转,观察 `ImuMain_GetData` 的 gyro_z 符号与约定一致,否则改 `PATH_GYRO_SIGN`;
- [ ] UART7 连小电脑(115200)、UART9 连 DT35、UART4 连遥控器;
- [ ] DT35 前/左安装方向与 `PATH_LASER_FRONT/LEFT_*` 一致;
- [ ] 墙表与实测一致(见 §7 待确认项)。

### 6.3 场地几何核对(PC)

```
python3 map_check.py
```
输出 `map_check.png` + 控制台报告(墙/路点/软硬膨胀/净距/穿墙检查)。
数据直接解析 `path_config.h`,与 C 代码永远同步。**改墙或路点后必须重跑一次。**

### 6.4 首跑建议

1. 先空转验证换算:直行 1m、原地转 90°,误差大则微调 `PATH_RPM_PER_M_S`/`PATH_Z_PER_RAD_S`;
2. 场地首跑开调试:`path_config.h` 置 `PATH_DEBUG=1` 并取消注释
   `PATH_DEBUG_UART_HANDLE huart8`,每 400ms 从 UART8 输出一行状态;
3. 重点观察墙 C 缺口(全场最窄)与墙 B 段:软包络内时间是正常现象,硬包络必须为 0;
4. 障碍物测试:路上放纸箱,确认 ≤12cm 停车、移开后自动恢复。

### 6.5 CSV 导出(检查离线剖面)

MCU 无文件系统,剖面在 RAM 只读。调试时在 commTask 里调
`PathSpeedProfile_DumpCsv(PathRunner_GetTrajectory(&n), n, &huart8)`,
主机串口工具存成 CSV,可核对每点 s/x/y/κ/v_ref/期望激光。

## 7. 错误处理与排查

### 7.1 状态/原因码速查(0x20 状态帧的 state/error 字段)

| state | 含义 |
|---|---|
| 0 INIT / 1 CALIB / 2 WAIT_START / 3 BUILD | 未出车,机器人应静止 |
| 4 RUN | 正常行驶(此时 error 可为 4=LASER_SLOW,正常) |
| 5 ARRIVED | 到达,刹车锁存 |
| 6 STOPPED | 故障停机,error=具体原因 |

| error(reason) | 含义 | 典型原因 → 处理 |
|---|---|---|
| 6 STOP_LASER_FRONT | 前激光 ≤12cm 且不允许回中 | 前方真有障碍→清障;期望墙异常→查墙表/激光安装 |
| 7 STOP_UPPER_LOST | 位姿链路/数据不可用 | 小电脑离线?UART7 接线?场地越界?查 0x11 帧与 CRC |
| 8 STOP_IMU_LOST | IMU 未 READY(含 10s 校准超时) | IMU 未插/线松/配置失败;重启观察 |
| 9 STOP_LASER_LOST | 前激光无帧 | UART9 接线/传感器供电 |
| 10 STOP_BUILD | 轨迹验收不过 | 起点离路线太远 / 墙表与真实不符 → 跑 map_check 找穿墙点 |
| 11 STOP_NUMERIC | NaN/Inf | 罕见;记录日志报修 |
| 12 STOP_MOTOR_LOST | 任一 VESC 离线 | 电机供电/CAN 线/ID |
| 13 STOP_HEADING | 起步朝向超 ±30° | 车摆正朝 +y 再上电 |
| 14 STOP_TIMEOUT | 20s 未到终点 | 沿途卡死(见 7.3)/路线被挡 |

### 7.2 复位与接管

- 任何 STOPPED/ARRIVED:刹车锁存,**手动遥控可直接解除锁存开走**;重新自主跑需要重新上电(设计如此:故障锁存靠断电复位)。

### 7.3 常见故障现象 → 排查

| 现象 | 排查顺序 |
|---|---|
| 上电一直不动,状态帧停在 1(CALIB) | IMU 是否 READY;查 USART1、IMU 供电;10s 后应转 STOP_IMU_LOST |
| 停在 2(WAIT_START) | 小电脑没发 0x11 / 帧校验不过 / 起点朝向超限(转 13) |
| 停在 3→转 10(STOP_BUILD) | 跑 `map_check.py` 看穿墙点;确认墙表=真实场地 |
| 行驶中贴墙急停(6) | 期望墙门控失效?确认 `exp_laser_front` 表(CSV)与实际激光安装一致 |
| 行驶中缓慢且 reason=4 频繁 | 正常兜底;若整段全程 4,查激光安装/墙表(期望墙错会一路限速) |
| 撞墙 | 硬包络不应有;先查墙表是否真实,再查 gyro 符号(反向会横漂) |
| 到不了终点 20s 超时 | 终点附近卡住:查 CSV 末段 κ 与激光读数;确认目标点 (0.5,3.7) |

### 7.4 现场最危险的三件事(再次强调)
