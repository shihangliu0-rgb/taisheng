# 机器人调试上位机 · Upper Computer

基于 Python + PyQt5 的串口调试上位机，支持 **USB 转 TTL / 无线数传 / 蓝牙 SPP / WiFi 透传（TCP）**，
提供键盘遥控映射与 PID 在线整定。

> 📄 **接入下位机请看 [`docs/PROTOCOL.md`](docs/PROTOCOL.md)** —— 该文档由代码自动生成，永远与实现一致。

---

## 快速开始

```bash
pip install -r requirements.txt
python run.py            # 或 python -m upper_computer
```

没有硬件？内置下位机模拟器（模拟一阶电机 + PID 闭环，会回 ACK / 遥测 / 曲线）：

```bash
python tools/simulator.py --tcp 8888
# 上位机里：类型选「网络 TCP」，host=127.0.0.1，port=8888，点连接
```

## 功能

### 通用
| 能力 | 说明 |
|---|---|
| 链路无关 | USB-TTL、无线数传、蓝牙 SPP 走串口；ESP8266/ESP32 等 WiFi 透传走 TCP，同一套协议 |
| 自动识别 | 端口列表自动标注 `[USB-TTL]` / `[无线/蓝牙]` |
| 断线自动重连 | 无线链路掉线后指数退避自动重连 |
| 帧格式可切换 | 二进制帧（默认，带 CRC16）/ ASCII 文本帧（`$NAME,args*XX`，便于串口助手调试） |
| **两种发送模式** | **实时发送**（按周期连续下发，默认 20ms/50Hz）／**配置后点击发送**（手动单次） |
| 安全 | Esc 急停、窗口失焦自动归零、心跳保活、关闭程序自动发急停 |

### 功能 1 —— 键盘映射（**全局生效**）
- **开启后在任意标签页都能用**：不管你正在看 PID、曲线还是控制台，WASD 都直接控制车
  （焦点在输入框/数字框里时自动放行，不影响打字；`Esc` 急停和 `F2` 开关任何时候都生效）
- `W` 前进 · `S` 后退 · `A` 左平移 · `D` 右平移 · `Q` 逆时针 · `E` 顺时针 · `空格` 制动
- **任意组合**：`W+A` 斜行、`W+E` 边走边转、`W+A+E` 斜着转……三轴分量独立解算
- 每个方向的**最大速度独立可调**（vx / vy / ω）
- `Shift` 加速档、`Ctrl` 慢速档，倍率可调
- 斜向归一化（`W+A` 不会比 `W` 快 1.41 倍）
- 加/减速斜坡，避免电流冲击，手感更线性
- 键位可在「设置」页自定义，按键状态实时可视化

### 功能 2 —— PID 在线整定
- 一键读取下位机当前 PID（单通道 / 全部），界面自动填充
- 编辑 `Kp / Ki / Kd / 积分限幅 / 输出限幅`；实时模式下改动即发送，手动模式下点击发送
- 下发阶跃目标值，或**方波激励**（幅值/周期可调）自动来回切换
- 实时响应曲线（目标 / 反馈 / 输出），自动缩放、可暂停、时间窗可调
- 参数固化到 Flash（`PID_SAVE`）
- 多通道 PID 表格，支持 4 轮速度环 + 角度环 + 角速度环 + 用户自定义

### 功能 3 —— 数据流 / 曲线（IMU 全通道，按需订阅）
- **44 个内置通道**：IMU 姿态角（roll/pitch/yaw、四元数）、陀螺仪、加速度计、磁力计、温度、
  里程计位移（odom_x/y/theta/dist）、实际速度、四轮目标/实际转速、电压电流、CPU 负载、
  8 个用户自定义通道
- **在上位机勾选要看哪些**，勾选结果通过 `STREAM_CFG(0x31)` 下发，
  **下位机只上报这几个通道，不用全发** —— 实测 3 通道 2 KB/s vs 全量 40 通道 15.5 KB/s，
  省 7.4 倍带宽，对无线链路很关键
- 分组树 + 搜索框 + 一键预设（姿态角 / 陀螺仪 / 加速度 / 位移 / 实际速度 / 轮速）
- **大容量回溯**：每通道默认 20 万点（50Hz 下约 1 小时），可调到 100 万点。
  过去的数据不会丢，随时拖回去看问题
- 鼠标**拖动平移、滚轮缩放、双击回到最新**，十字光标显示各通道读数
- 暂停采集、导出 CSV

### 附加调试功能
- **遥测状态栏**：实际速度、航向角、电池电压、状态、错误码
- **原始数据控制台**：RX/TX 帧解析显示、HEX 原始字节、CRC 错误与丢弃字节统计、TX 帧率
- **透传输入框**：直接发文本命令（`RAW_TEXT`），或 `hex: AA 55 ...` 发裸字节
- **模式切换**：IDLE / MANUAL / AUTO / PID_TUNE
- 配置自动保存到 `~/.upper_computer/config.json`

## 项目结构

```
upper_computer/
  protocol.py   ← 协议唯一事实来源（改这里，文档和编解码同时生效）
  link.py       ← 串口/TCP 链路，收发线程 + 自动重连
  motion.py     ← 键盘映射 → 速度解算（组合键/归一化/斜坡）
  config.py     ← 配置持久化
  plot.py       ← 可回溯示波器控件（大缓冲/缩放/平移/CSV，无额外依赖）
  channels.py   ← 数据通道勾选树（IMU/里程计/轮速/自定义）
  ui.py         ← 主界面
tools/
  gen_protocol_doc.py  ← 自动生成 docs/PROTOCOL.md
  simulator.py         ← 下位机模拟器
docs/PROTOCOL.md       ← 数据格式文档（自动生成）
tests/                 ← 协议、通道、运动解算单元测试
```

## 文档自动更新

`docs/PROTOCOL.md` 由 `upper_computer/protocol.py` 自动生成：

```bash
python tools/gen_protocol_doc.py
```

**上位机每次启动也会自动检查并重新生成**，所以只要你改了协议，文档立刻跟着更新，不会出现文档和代码对不上的情况。

## 扩展新命令

在 `upper_computer/protocol.py` 加一条即可，编解码 + 文档全部自动生效：

```python
class Cmd(IntEnum):
    ...
    MY_CMD = 0x40          # 0x40–0x7E 区间预留给自定义

MSG_MY_CMD = _reg(Message(
    Cmd.MY_CMD, "MY_CMD", "PC->MCU", "我的自定义命令",
    [Field("foo", "u16", "-", "说明"),
     Field("bar", "f32", "A", "电流")],
))
```
