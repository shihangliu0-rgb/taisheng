# 机器人运动控制上位机

电脑通过无线 DAPLink 的透明串口控制机器人。当前支持底盘键盘控制、抬升与下沉动作，并实时显示下位机回传的 yaw、DT35 距离和 PNP 触发状态。

## 环境

- Python 3.10 或更高版本
- PyQt6
- pyserial

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## 运行

```powershell
python main.py
```

程序启动后选择无线 DAPLink 对应的串口并连接。串口参数固定为 `115200 / 8N1`。

## 控制

第一页可直接发送抬升、下沉、2006 前进和前后腿动作。每次发送“2006前进”，两台 M2006 输出轴分别从当前位置前进 `360 deg`。

前腿动作同时控制两台 RS00，后腿动作同时控制两台达妙。放平动作先回到 `0 deg`，再运动到 `90 deg`。

| 按键 | 整体速度方向 |
|---|---|
| W | `+vy`，前进 |
| S | `-vy`，后退 |
| A | `-vx`，左平移 |
| D | `+vx`，右平移 |
| Q | `+wz`，逆时针 |
| E | `-wz`，顺时针 |

平移组合键会保持合速度不超过设置值。相反方向同时按下时互相抵消。

速度设置沿用参考工程：

- 平移速度：`0.05-5.00 m/s`，默认 `0.05 m/s`，步进 `0.05 m/s`。
- 旋转速度：`0.01-10.00 rad/s`，默认 `0.01 rad/s`，步进 `0.01 rad/s`。

当前下位机沿用参考工程的底盘控制量，界面数值用于生成控制指令，不代表已经标定的实车物理速度。

按键或速度变化时，上位机会立即发送新指令。运动期间以 10 Hz 发送保活帧，静止时不周期发送。松开按键、关闭键盘控制、窗口失去焦点、断开串口或退出程序时，速度会恢复为零。断开和退出前会连续发送三帧零速度。

通信格式和接收端要求见 [遥测.md](遥测.md)。
