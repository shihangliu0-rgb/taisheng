# 机器人运动通信协议

本文档记录电脑上位机与机器人之间的串口协议，供下位机接收程序和遥控程序共用。当前包含速度指令、抬升动作、yaw、DT35 距离和 PNP 状态回传。

## 串口参数

| 参数 | 数值 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |
| 运动保活周期 | 100 ms，10 Hz |

无线 DAPLink 工作在透明串口模式，协议不包含 AT 指令或无线模块配置命令。

## 坐标系

- `+vx`：机器人向右平移。
- `+vy`：机器人前进。
- `+wz`：机器人逆时针旋转。

三个字段表示机器人整体运动方向，不是单个车轮 RPM。当前下位机沿用现有底盘控制量，不对实际物理速度做标定。

## 速度指令帧

每帧固定 9 字节，多字节整数采用小端序：

| 字节偏移 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | `header_0` | `uint8_t` | - | 固定 `0xA5` |
| 1 | `header_1` | `uint8_t` | - | 固定 `0x5A` |
| 2-3 | `vx_cmd` | `int16_t` | 控制量 | X 轴整体运动指令 |
| 4-5 | `vy_cmd` | `int16_t` | 控制量 | Y 轴整体运动指令 |
| 6-7 | `z_cmd` | `int16_t` | 控制量 | Z 轴整体旋转指令 |
| 8 | `checksum` | `uint8_t` | - | 字节 2-7 的逐字节异或 |

校验计算：

```c
checksum = frame[2] ^ frame[3] ^ frame[4] ^
           frame[5] ^ frame[6] ^ frame[7];
```

帧头不参与校验。负数使用有符号 16 位补码表示。

## 抬升动作帧

动作帧固定 3 字节：

| 字节偏移 | 字段 | 说明 |
|---|---|---|
| 0 | `header_0` | 固定 `0xA5` |
| 1 | `header_1` | 固定 `0x5B` |
| 2 | `action` | 动作编号，见下表 |

| 动作编号 | 上位机按钮 | 板端动作 |
|---:|---|---|
| `0x00` | 下沉 | 两台 RS00 和两台达妙回到 `0 deg` |
| `0x01` | 抬升 | 两台 RS00 和两台达妙运动到 `180 deg` |
| `0x02` | 2006前进 | 两台 M2006 分别相对当前位置前进 `360 deg` |
| `0x03` | 前腿收平 | 两台 RS00 运动到 `270 deg` |
| `0x04` | 前腿放平 | 两台 RS00 先回 `0 deg`，再运动到 `90 deg` |
| `0x05` | 前腿放下 | 两台 RS00 运动到 `180 deg` |
| `0x06` | 后退收平 | 两台达妙运动到 `270 deg` |
| `0x07` | 后腿放平 | 两台达妙先回 `0 deg`，再运动到 `90 deg` |
| `0x08` | 后腿放下 | 两台达妙运动到 `180 deg` |

## Yaw 回传帧

下位机每 50 ms 回传一次 yaw，帧长固定为 5 字节，多字节整数采用小端序：

| 字节偏移 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | `header_0` | `uint8_t` | - | 固定 `0xA5` |
| 1 | `header_1` | `uint8_t` | - | 固定 `0x5C` |
| 2-3 | `yaw_cdeg` | `int16_t` | `0.01 deg` | 归零并滤波后的 yaw 角 |
| 4 | `checksum` | `uint8_t` | - | 字节 2、3 异或 |

例如 `yaw = 12.34 deg` 时，回传帧为 `A5 5C D2 04 D6`。

## DT35 距离回传帧

每路 DT35 使用固定 5 字节帧，多字节整数采用小端序：

| 字节偏移 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | `header` | `uint8_t` | - | 固定 `0xAA` |
| 1 | `address` | `uint8_t` | - | F 为 `0x40`，L 为 `0x41` |
| 2-3 | `distance_cm` | `uint16_t` | cm | DT35 距离 |
| 4 | `checksum` | `uint8_t` | - | 字节 0-3 的逐字节异或 |

## PNP 状态回传帧

PNP 电压严格大于 `23 V` 时触发值为 1，否则为 0。每路使用固定 5 字节帧：

| 字节偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | `header` | `uint8_t` | 固定 `0xAB` |
| 1 | `address` | `uint8_t` | PNP_F 为 `0x40`，PNP_B 为 `0x41` |
| 2 | `trigger` | `uint8_t` | 未触发为 0，触发为 1 |
| 3 | `reserved` | `uint8_t` | 固定为 0 |
| 4 | `checksum` | `uint8_t` | 字节 0-3 的逐字节异或 |

主控超过 `500 ms` 未收到某一路 PNP 合法帧时，将该路动作触发变量清零，并向上位机回传一次 0。

## 按键映射

| 按键 | `vx` | `vy` | `wz` |
|---|---:|---:|---:|
| W | 0 | 正 | 0 |
| S | 0 | 负 | 0 |
| A | 负 | 0 | 0 |
| D | 正 | 0 | 0 |
| Q | 0 | 0 | 正 |
| E | 0 | 0 | 负 |

W/S、A/D、Q/E 各自同时按下时，对应轴速度为零。斜向平移时两个轴均乘以 `1/sqrt(2)`，保证合速度大小不超过设定的平移速度。

## 速度范围

上位机设置沿用参考工程：

| 参数 | 最小值 | 最大值 | 默认值 | 步进 |
|---|---:|---:|---:|---:|
| 平移速度 | 0.05 m/s | 5.00 m/s | 0.05 m/s | 0.05 m/s |
| 旋转速度 | 0.01 rad/s | 10.00 rad/s | 0.01 rad/s | 0.01 rad/s |

打包前分别乘以 1000 并四舍五入，转换为 `mm/s` 和 `mrad/s` 整数。

## 示例

| 指令 | 9 字节十六进制帧 |
|---|---|
| 停止 | `A5 5A 00 00 00 00 00 00 00` |
| 以 0.05 m/s 前进 | `A5 5A 00 00 32 00 00 00 32` |
| 以 0.05 m/s 后退 | `A5 5A 00 00 CE FF 00 00 31` |
| 以 0.05 m/s 右移 | `A5 5A 32 00 00 00 00 00 32` |
| 以 0.01 rad/s 逆时针旋转 | `A5 5A 00 00 00 00 0A 00 0A` |
| 默认速度前进并右移 | `A5 5A 23 00 23 00 00 00 00` |

## 接收端要求

1. 按字节搜索连续帧头 `A5 5A`，找到后再接收剩余 7 字节。
2. 帧长度和异或校验均正确后，才更新速度目标。
3. 上电后的目标速度必须初始化为零。
4. 建议超过 200 ms 未收到合法帧时，将三个速度目标全部置零。
5. 校验失败时丢弃当前帧并重新搜索帧头，不得沿用错误帧中的速度。
6. 控制输入变化时立即发送一帧；运动期间以 10 Hz 发送保活帧，静止状态不需要周期发送。

## 后续遥测扩展

后续增加电压、轮速或故障状态时，应分配新的第二帧头和固定帧长，不能直接改变现有三类帧的布局。
