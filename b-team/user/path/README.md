# 人工直线路径辅助与安全层

本目录只从 `arena/01a00390-taisheng` 的 `user/path_planner/path_config.h`
提取场地地图。没有复制该分支的样条曲线、自动跟踪、FSM、小电脑定位或
自动驾驶控制；底盘平移指令始终来自现有 LoRa 遥控器。

## 坐标与一次性激光定点

- 地图坐标：X 向右，Y 向前；正常控制时 yaw 锁定为 `0°`。
- 场地：`3.0 m × 6.0 m`。
- 机器人：长 `0.617 m`、宽 `0.440 m`。
- DT35 量程（子板示教窗口）：**前激光 5–140 cm，左激光 5–240 cm**；
  两只激光装在**车体最前端/最左端**，读数从车体边缘起算（安装
  偏移即半车长 `0.3085 m` / 半车宽 `0.2200 m`）。
- 左 DT35 扫描西边界内侧面 `x = 0.049 m`：常规侧贴西墙读数约
  `10 cm`，镜像侧贴东墙读数约 `2.36 m`——`2.4 m` 量程下两侧都能在
  起点**静止锚定**。启动时只等待左 DT35 按接收时间戳收齐 3 个新
  样本，取中值作为 X 定点距离；该采样独立于安全限速的三点保守
  最小值。
- 初始机器人中心 Y 恒为车长一半，即 `0.6170 / 2 = 0.3085 m`。
- 前 DT35 不参与、不等待也不校验初始定位，仅保留运行期 `+Y` 动态
  安全限速与回程末段贴面校正职责。

设左光中值距离为 `d_l`，定点周期 IMU 实测 yaw 为 `ψ`，则机器人中心为：

```text
x = 0.049 + (0.220 + d_l) × cos(ψ)
y = 0.6170 / 2 = 0.3085
```

实现还计算左光墙面交点，确认其落在西边界有效 Y 范围内；不再计算或校验
前光到墙 B 的初始定位几何。定点只成功一次：成功时记录融合里程计位置
`(odom_x, odom_y)`，保存地图偏移
`(x - odom_x, y - odom_y)`；之后地图坐标始终为该偏移加实时融合位置，
不再用激光重置，也不依赖上位机绝对定位。

`0.2700 m` 与 `0.3285 m` 现在只表示地图碰撞计算的车体边界净空（半车宽
加 `5 cm`、半车长加 `2 cm`），不再表示启动位置。

`path_map.c` 保留参考地图的 4 面边界墙与 3 段内墙：

对抗赛双方场地互为左右镜像，换场后机器人贴**东墙**起步、车头仍朝 `+Y`。

| 墙 1 | `(1.05,1.07)–(3,1.12)`（贴东墙） | `(0,1.07)–(1.95,1.12)`（贴西墙） |

| 路线 | 上、右、上、左、上、右 | 上、左、上、右、上、左（X 段方向与终点取镜像：`0.52 / 2.64 / 2.50`） |
| 起点 X | `0.049 + 0.175 + d_l`（实测） | `2.626 m`（假定贴东墙对称摆放） |

**场地要求**：镜像侧跑之前，需要把 3 段内墙物理摆放到上表镜像位置
（墙 1、墙 C 贴西墙，墙 B 贴东墙）；4 面边界墙不动。机器人贴东墙起步，
与西墙间距约 `15 cm`（与常规侧对称）。

### 自动识别与锚定

- **场地不是四面全封闭**：西边界在南墙与墙 1 之间（`y < 1.07`）是
  **通道开口，没有墙体**（路线用不到该通道）。镜像布置下起始区
  左光朝西正对这个开口，读不到任何回波。
- 常规侧：左光贴西墙读数约 `10 cm`，静止收齐 3 样本即锚定
  `x ≈ 0.37`。
- 镜像侧：左光在线但无样本（面向开口饱和 `240 cm`）；向北前出约
  `6 cm` 后前光读到第一堵前墙（墙 B'，起点车头面距其 `145.8 cm`
  略超 `1.4 m` 量程）→ 判定镜像侧：X 用贴东墙起点 `2.626 m`，
  Y 用 `2.075 − 0.3085 − d_front` 反算。自动模式的"盲走找墙"状态
  自动完成这段前出。
- 兜底：若场地为封闭变体（西侧起始区有墙），左光会读到 `~2.36 m`
  并静止锚定，锚定 X 越过半场（1.5 m）同样正确判定镜像侧。
- 左光饱和是否按"墙在量程边界"保守限速由左光实际面向决定（车头
  靠近 `+Y` 时朝西、`-Y` 时朝东）：面向本侧近墙保守限速，面向
  开口/空旷场地只对量程内真实目标限速。

## 自动行驶（无遥控器：上电 5 s 自启，到终点停车鸣笛）

上电后自动完成锚定，**延时 5 s**（`PATH_AUTO_START_ON_BUTTON=0` 的
默认模式）自动沿去程 6 段行驶：常规侧锚定即出发；镜像侧先以精调速
`+Y` 盲走找第一堵前墙锚定后继续。距段终点 `0.5 m` 内自动换精调档。
到达终点后**整组制动停车**、蜂鸣器（PC15，与开机提示音同款 500 Hz）
鸣响 160 ms，`auto_state = DONE`，随后**交接释放**（一次性测试
语义）：融合里程计停跑（freertos 任务据 `Path_OdometryReleased()`
不再调用 `PathLineImu_Run1ms`）、地图净空保护与分段/回程功能全部
关闭、肩键放开、按键 1/2 失效——之后遥控完全人工驾驶，仅保留
DT35 前/左动态激光限速。注意：交接释放只在自动跑完全程时发生；
中途人工接管（`auto_state = OFF`）则保留全部地图/分段功能。

- 自动指令与遥控指令走**同一条 1 ms 安全管线**：前/左激光限速与硬
  阻挡、地图净空限速、沿墙滑动、分段推进全部生效；若被障碍硬停，
  自动模式原地等待，障碍移除后继续。
- **人工接管优先**：自动行驶期间任意摇杆偏移（>10）或除按键 3 外的
  任意按键按下，立即永久退出自动、遥控接管。
- **按键启动接口（预留）**：按键 3 按下沿调用 `Path_AutoStartTrigger()`
  ——默认延时模式下可用它提前启动；把 `path.h` 的
  `PATH_AUTO_START_ON_BUTTON` 置 1 即切换为"只由按键 3（或直接调用
  该函数）启动"，5 s 延时不再生效。
- 诊断 `auto_state`：0 等待启动 / 1 等待就绪 / 2 镜像盲走找墙 /
  3 自动行驶 / 4 到点完成 / 5 人工接管退出。

## yaw=0 锁定

所有遥控及其他速度来源的旋转分量在行驶阶段都由本层置为 0，肩键不
产生旋转；到点交接后放开肩键（见"自动行驶"）。IMU 进入 READY 或
离线恢复后，本层重新使能原有 yaw 闭环并把目标设为 `0°`。初始激光
定点例外：几何反算使用该周期 IMU 实测 yaw 投影安装偏移与射线，而
不是假定机器人已经精确为 `0°`。

**坐标系约定**：`Chassis_SetVelocity` 的 vx/vy 是**车体系**（X 向右、
Y 向前），DT35 也装在车体上；激光限速始终按车体分量判断（前光只
限制 `vy>0`，左光只限制 `vx<0`）。涉及地图几何的计算（净空方向、
自动行驶指令）先用实测 yaw 把命令旋到地图系再处理。

本模块只保留**起始区 → 终点**的去程功能（常规侧与镜像侧两张地图
与路线）；回程、掉头与单轴辅助均已移除，到达终点即交人工接手。

## 动态安全距离

前 DT35（`0x40`）只限制 `+Y` 前进分量；左 DT35（`0x41`）只限制
`-X` 向左分量。反方向离开障碍的命令不会被对应激光阻止。限速使用：

```text
d_safe = d_base + v × 0.080 s + v² / (2 × 2.0 m/s²)
```

- 前基础净距：`12 cm`（从车头面起算）；释放滞回到 `14 cm`。
- 左基础净距：`5.5 cm`（从车侧面起算，等效旧安装的物理净距，
  保证贴西墙走廊 `x = 0.36` 可达）；释放滞回到 `7.5 cm`。
- 速度取编码器实测朝障碍速度与当前请求速度中较大者计算动态需求；输出
  速度由实测距离反解公式后限幅。若实测逼近速度仍高于该距离允许值超过
  `0.03 m/s`，立即触发底盘制动；进入硬阻挡时若上一安全输出仍朝向障碍，
  即使里程计暂时无效也制动。反向逃离命令保留，横移不能掩盖逼近惯性。
- DT35 子板实际每 `50 ms` 更新，输出被钳在 `5 cm` 到各自量程上限
  （前 `140 cm`、左 `240 cm`）。安全层保留最近 3 点的保守最小值：
  距离减小首帧生效，距离增大需覆盖旧样本后才释放。`0` 绝不解释为
  "无回波自由"；若在线状态下读到异常 0，本层钳为 `5 cm`。
- 前光 `1.4 m` 量程提供完整制动距离：巡航速度不再被量程上限
  变相压低，只在真正接近障碍时按制动公式逐渐限速。
- 按用户要求，任一激光离线时**不因离线停车**，仅在诊断中标记 offline，
  并跳过该方向的激光限速。

地图静态墙另作为无激光方向的辅助保护：把车体命令用实测 yaw 旋到地图
系后，按机器人外形膨胀内墙并对行进方向做射线净空限速；已在膨胀带内
时只禁止继续向墙内的分量，沿墙切向平移保持可用（否则一次越界就会被
锁死在膨胀带内）。它依赖纯里程计，会随漂移降低精度，不能代替对实际
障碍的观察；右侧和后方没有 DT35，不能宣称具备动态障碍激光保护。
另外注意：段间直角换向满杆起步时，四轮各自独立跟踪目标转速，反转轮
滞后会产生约 10–15 cm 的横向暂态漂移；换向起步建议先半杆再加速。

## 接入与诊断

- `Path_Init()`：FreeRTOS 创建任务前调用。
- `Path_SubmitRemoteCommand()`：LoRa 本机控制帧提交摇杆和六键。
- `Path_Run1ms()`：在融合里程计每 1 ms 更新后执行，并把变化后的安全
  输出提交给底盘。
- `Path_NotifyRemoteOffline()`：LoRa 200 ms 超时通知。
- `Path_ReplaceNonRemoteCommand()`：无小电脑模式下防止原上位机速度协议
  旁路人工安全输出；动作协议不受影响。
- `Path_GetDiagnostics()`：读取定点有效性、左光样本数/中值距离/墙面交点、
  分段、地图位姿、镜像侧标志 `map_mirrored`、回程标志 `return_mode`/
  `return_yaw_aligned`/`return_complete`/`return_reverse`（倒车回程）、
  激光在线/安全距离、动态限速、
  yaw 锁定以及原始/输出指令。常规侧兼容保留的前光初始样本、距离和交点
  字段恒为 `0`；镜像侧前光初始距离为锚定时的实测值。

## 地图绘制脚本

`user/path/maps/map_draw.py` 用 Python + matplotlib 生成常规侧与镜像侧的场地
俯视图（墙、路线、机器人起始位姿），数据与 `path_map.c` 完全一致：

```bash
pip install matplotlib
python user/path/maps/map_draw.py                 # 生成 map_normal.png 与 map_mirrored.png
python user/path/maps/map_draw.py --side mirrored # 只画镜像侧
python user/path/maps/map_draw.py --return        # 画回程路线（map_*_return.png）
```

脚本自动检测中文字体（微软雅黑/苹方/Noto Sans CJK 等），找不到时标注
回退英文。

## 全路线物理闭环仿真

`user/path/sim/run_sim.sh` 编译真实的 `path.c/path_map.c/
path_localization.c/path_safety.c`，按工程源码逐条复刻底盘混控、IMU
yaw 闭环、DT35 子板量化与遥控映射，闭环验证常规/镜像 × 全速/谨慎共
4 个场景的完整路线（锚定 → 去程 6 段 → 掉头 → 回程 6 段 → 归零），
输出事件日志、CSV 轨迹与结论；`plot_sim.py` 绘制轨迹图。详见
`user/path/sim/仿真报告.md`。
