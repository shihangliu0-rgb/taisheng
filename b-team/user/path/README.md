# DT35 全局路径

不用 IMU。等前/左 DT35 有数据后，用左光判一次场地，然后载入
`path.h` 里对应那一套宏。自动速度按到目标的剩余厘米做 PID：
远了顶满 150，近了减速。轮速闭环仍在 VESC。

改某一侧的阈值 / PID / 滑停：只改 `path.h` 里那一块宏。

## 怎么跑

1. 车头朝 `+Y` 摆好。上电保持静止。
2. 两只激光在线后，用左光一次判定侧别（之后不再改）：
   - 左光 `< 100 cm`：常规侧（贴西墙）→ 载入 `PATH_*`
   - 左光 `≥ 100 cm`：镜像侧（贴东墙）→ 载入 `PATH_MIRROR_*`
3. 上电不跑。按左侧 **KEY_3（PC0）** 后按下面 4 段开。第 4 段到点即终点。

| 段 | 常规侧 | 镜像侧 | 到点 |
| --- | --- | --- | --- |
| 0 | 前进 `+Y` | 前进 `+Y` | 前光 `≤ PATH_FRONT_ARRIVE_CM` / `PATH_MIRROR_FRONT_ARRIVE_CM` |
| 1 | 右移 `+X` | 左移 `-X` | 常规：左光 `≥ PATH_LEFT_FAR_CM`；镜像：左光 `≤ PATH_MIRROR_LEFT_NEAR_CM` |
| 2 | 前进 `+Y` | 前进 `+Y` | 前光再到到点阈值（不看左光） |
| 3 | 左移 `-X` | 右移 `+X` | 常规：左光 `≤ PATH_LEFT_NEAR_CM`；镜像：左光 `≥ PATH_MIRROR_LEFT_FAR_CM` → **结束** |

默认数：前 26、近 32、远 222。你说的「前 26 → 左移到 32 → 前 26 → 右移到 222 → 终点」是镜像侧。
常规侧左右对调：前 26 → 右移到 222 → 前 26 → 左移到 32 → 终点。

到点后刹住滑停（`PATH_AUTO_SETTLE_MS` / `PATH_MIRROR_SETTLE_MS`，默认 400 ms），再走下一段。

## 其它规则

| 项 | 规则 |
| --- | --- |
| 读数 0 | 钳到 5 cm |
| 激光离线 | 不启动；该段不到点 |
| 摇杆/按键（除 3） | 永久退出自动 |
| 全局硬停 | **任何阶段**：前光挡 `+Y`，左光挡 `-X`（`PATH_LASER_STOP_CM` / `PATH_MIRROR_LASER_STOP_CM`） |
| 串口映射 | 主控收包时 0x40/0x41 对调后再当左/前用 |
