# DT35 全局路径

`path.c` 不再用 IMU 里程计。等前/左 DT35 有数据后，用左光判镜像，
再按激光阈值跑 4 段。yaw 仍尽量锁 0°，但不参与到点判断。

## 怎么跑

1. 车头朝 `+Y` 摆好。上电保持静止。
2. 两只激光在线后，用左光一次判定侧别（之后不再改）：
   - 左光 `< 100 cm`：常规侧（贴西墙）
   - 左光 `≥ 100 cm`：镜像侧（贴东墙）
3. 延时 5 s 后按下面 4 段开。

| 段 | 常规侧 | 镜像侧 | 到点条件 |
| --- | --- | --- | --- |
| 0 | 前进 `+Y` | 前进 `+Y` | 前光从大于 26 cm 降到 `≤ 26 cm` |
| 1 | 右移 `+X` | 左移 `-X` | 常规：左光 `≥ 222 cm`；镜像：左光 `≤ 32 cm` |
| 2 | 前进 `+Y` | 前进 `+Y` | 前光再次降到 `≤ 26 cm`（前进段不看左光） |
| 3 | 左移 `-X` | 右移 `+X` | 常规：左光 `≤ 32 cm`；镜像：左光 `≥ 222 cm` |

到点后刹住滑停 400 ms，再走下一段。4 段结束鸣笛，交遥控。

你描述的「前 26 → 左移到左光 32 → 前 26 → 右移到左光 222」就是镜像侧。
后两段（再前进、再平移）还没给阈值，需要的话补数字即可。

## 其它规则

| 项 | 规则 |
| --- | --- |
| 读数 0 | 钳到 5 cm |
| 激光离线 | 不启动；行驶中该段到点条件不成立，不会误切段 |
| 摇杆/按键（除 3） | 永久退出自动 |
| 遥控接手后 | 前光 < 10 cm 挡 `+Y`，左光 < 10 cm 挡 `-X` |

## 现在不用的东西

`path_line_imu` 定位、`path_localization.c`、`path_safety.c`、地图净空
`path.c` 不再调用。
