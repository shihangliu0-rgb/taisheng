# 固定点自动行驶（最小版）

当前 `path.c` 只做一件事：用 **PathLineImu 的 IMU 位移**，从上电假定起点
跑完 6 段固定直线。激光定点、镜像识别、地图净空、DT35 限速全部拿掉，
之后再往回加。

## 怎么跑

1. 车摆在假定起点，车头朝 `+Y`。侧别由 `path.h` 的 `PATH_USE_MIRRORED` 编译期选定，**运行时不判断**：
   - `0`：常规侧，贴西墙，中心约 `(0.374, 0.3085)`
   - `1`：镜像侧，贴东墙，中心约 `(2.626, 0.3085)`
2. 上电保持静止，等 IMU READY 且加速度零偏完成（约 5–6 s）。
3. 延时 5 s 后自动按对应 6 段开：

常规侧（`PATH_USE_MIRRORED=0`）：

| 段 | 轴 | 终点 |
| --- | --- | --- |
| 0 | Y+ | `1.600 m` |
| 1 | X+ | `2.480 m` |
| 2 | Y+ | `2.600 m` |
| 3 | X− | `0.360 m` |
| 4 | Y+ | `3.700 m` |
| 5 | X+ | `0.500 m` |

镜像侧（`PATH_USE_MIRRORED=1`）：

| 段 | 轴 | 终点 |
| --- | --- | --- |
| 0 | Y+ | `1.600 m` |
| 1 | X− | `0.520 m` |
| 2 | Y+ | `2.600 m` |
| 3 | X+ | `2.640 m` |
| 4 | Y+ | `3.700 m` |
| 5 | X− | `2.500 m` |

地图坐标 = 起点 + `imu_position`。距段终点 0.8 m 内换精调档。到终点
停车鸣笛，之后遥控人工开。摇杆/按键（除按键 3）立即永久退出自动。

## 现在不用的东西

`path_localization.c`、`path_safety.c`、DT35、镜像地图仍留在工程里，
`path.c` 不再调用。加回时从这里接。
