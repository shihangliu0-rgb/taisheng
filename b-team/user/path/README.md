# 固定点自动行驶（最小版）

当前 `path.c`：用 **PathLineImu 的 IMU 位移** 从上电假定起点跑完 6 段。
DT35 只做近距限制——前光或左光在线且读数 **小于 10 cm 立即整车停车**。
激光定点、镜像识别、地图净空、动态限速仍未加回。

## 怎么跑

1. 车摆在假定起点，车头朝 `+Y`。侧别由 `path.h` 的 `PATH_USE_MIRRORED` 编译期选定，**运行时不判断**：
   - `0`：常规侧，贴西墙，中心约 `(0.374, 0.3085)`
   - `1`：镜像侧，贴东墙，中心约 `(2.626, 0.3085)`
2. 上电保持静止，等 IMU READY 且加速度零偏完成（约 5–6 s）。
3. 延时 5 s 后自动按对应 6 段开：

常规侧（`PATH_USE_MIRRORED=0`）：

| 段 | 轴 | 终点 |
| --- | --- | --- |
| 0 | Y+ | `1.600 m` |
| 1 | X+ | `2.480 m` |
| 2 | Y+ | `2.600 m` |
| 3 | X− | `0.360 m` |
| 4 | Y+ | `3.700 m` |
| 5 | X+ | `0.500 m` |

镜像侧（`PATH_USE_MIRRORED=1`）：

| 段 | 轴 | 终点 |
| --- | --- | --- |
| 0 | Y+ | `1.600 m` |
| 1 | X− | `0.520 m` |
| 2 | Y+ | `2.600 m` |
| 3 | X+ | `2.640 m` |
| 4 | Y+ | `3.700 m` |
| 5 | X− | `2.500 m` |

地图坐标 = 起点 + `imu_position`。距段终点 0.8 m 内换精调档。到终点
停车鸣笛，之后遥控人工开。摇杆/按键（除按键 3）立即永久退出自动。

## DT35 限制

| 项 | 规则 |
| --- | --- |
| 前光 `0x40` / 左光 `0x41` | 任一在线且 `< PATH_LASER_STOP_CM`（10 cm）→ `Chassis_StopAll` |
| 读数 0 | 钳到 5 cm，因此也会停 |
| 离线 | 不停、不改自动状态 |
| 距离回到 ≥ 10 cm | 自动继续原段，不退出 `DRIVE` |

不用来定点，不判镜像。常规侧段 3 终点 `x=0.36` 时左光大约 9 cm，
会被刹住；摆位左光约 10.5 cm，起点本身刚好在阈值外。

## 现在不用的东西

`path.c` 不再调用。加回时从这里接。
