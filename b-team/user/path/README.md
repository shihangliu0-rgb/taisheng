# DT35 全局路径

不用 IMU。等前/左 DT35 有数据后，用左光判镜像，按激光阈值跑 4 段。
每 1 ms 用「当前读数 − 目标」做 PID，差值大就快、接近目标就慢。

## 怎么跑

1. 车头朝 `+Y` 摆好。上电保持静止。
2. 两只激光在线后，用左光一次判定侧别（之后不再改）：
   - 左光 `< 100 cm`：常规侧（贴西墙）
   - 左光 `≥ 100 cm`：镜像侧（贴东墙）
3. 延时 5 s 后按下面 4 段开。第 4 段到点即终点。

| 段 | 常规侧 | 镜像侧 | 到点 / PID 目标 |
| --- | --- | --- | --- |
| 0 | 前进 `+Y` | 前进 `+Y` | 前光从大于 26 降到 `≤ 26 cm` |
| 1 | 右移 `+X` | 左移 `-X` | 常规：左光 `≥ 222`；镜像：左光 `≤ 32` |
| 2 | 前进 `+Y` | 前进 `+Y` | 前光再到 `≤ 26 cm`（不看左光） |
| 3 | 左移 `-X` | 右移 `+X` | 常规：左光 `≤ 32`；镜像：左光 `≥ 222` → **结束** |

你说的「前 26 → 左移到 32 → 前 26 → 右移到 222 → 终点」是镜像侧。
常规侧左右对调：前 26 → 右移到 222 → 前 26 → 左移到 32 → 终点。

到点后刹住滑停 400 ms，再走下一段；最后一段到点鸣笛交遥控。

## PID

误差 = 当前激光到目标的剩余厘米（只取正）。

`cmd = clamp(Kp·e + Ki∫e + Kd·de/dt, ±150)`

| 参数 | 值 |
| --- | --- |
| `PATH_PID_KP` | 4.0 |
| `PATH_PID_KI` | 1.2 |
| `PATH_PID_KD` | 0.05 |
| 输出限幅 | ±150 |

远距离饱和 150；前光还差 10 cm 时大约 40。换段 / 滑停清积分。

## 其它规则

| 项 | 规则 |
| --- | --- |
| 读数 0 | 钳到 5 cm |
| 激光离线 | 不启动；该段不到点 |
| 摇杆/按键（除 3） | 永久退出自动 |
| 遥控接手后 | 前光 < 10 cm 挡 `+Y`，左光 < 10 cm 挡 `-X` |
