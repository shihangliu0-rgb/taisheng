# 遥控器输入与下位机对接说明

## 统一抗抖余量

根据实测静止抖动，六路模拟量统一使用 `10` 个计数的余量。摇杆映射值在 `128 +/- 10` 内统一输出 `128`；肩键原始 ADC 变化不超过 `10` 时保持上一次稳定值，不为每一路单独设置参数。

## 当前软件边界

`user/RemoteInput.c` 和 `user/RemoteInput.h` 只负责遥控器本身：ADC 摇杆采样、开关/按键扫描、状态变化提示音和上电提示音。

`user/Remote.c` 和 `user/Remote.h` 只保存可供其他模块读取的遥控数据，当前没有下位机通信协议。以后增加通信时，把打包、发送和协议状态放在 `Remote.c`，不要把通信代码加入 `RemoteInput.c`。

## 数据接口

```c
extern volatile remote_data_t remote_data;
extern volatile uint16_t remote_shoulder_adc[REMOTE_SHOULDER_NUM];
extern volatile uint16_t remote_axis_adc[REMOTE_AXIS_NUM];
extern remote_adc_state_t remote_adc_state;
```

`remote_data` 字段如下：

| 字段 | 含义 | 范围 |
| --- | --- | --- |
| `left_shoulder` / `right_shoulder` | 左右肩键 ADC 稳定值 | `0..4095` |
| `left_x` / `left_y` | 左摇杆 X/Y | `0..255`，中心约 `128` |
| `right_x` / `right_y` | 右摇杆 X/Y | `0..255`，中心约 `128` |
| `switch_state[0..5]` | 从左到右六个开关 | `0` 断开，`1` 闭合 |
| `key_state[0..11]` | 左侧六键后右侧六键 | `0` 松开，`1` 按下 |

按键原理图已有 10K 上拉到 3V3，按下接地，因此按键低电平有效且 GPIO 不再打开内部上下拉；开关原理图的输入节点由 10K 上拉到 3V3，闭合后接 GND，因此开关也为低电平有效，GPIO 不再打开内部上下拉。

## 引脚映射

### 摇杆

| 逻辑量 | 当前引脚 | ADC 通道 | DMA 顺序 |
| --- | --- | --- | --- |
| 右 X | `PC2` | ADC2_IN12 | ADC2[0] |
| 右 Y | `PC3` | ADC2_IN13 | ADC2[1] |
| 左 X | `PB0` | ADC2_IN8 | ADC2[2] |
| 左 Y | `PB1` | ADC2_IN9 | ADC2[3] |

摇杆实测的 12 位 ADC 标定点保存在 `RemoteInput.c` 的 `remote_axis_cal` 中。中心值取静止波动区间的中值，最小值和最大值取两只摇杆的共同实测范围：

```text
右 X: min=10, mid=2103, max=4080
右 Y: min=10, mid=1960, max=4080
左 X: min=10, mid=2142, max=4080
左 Y: min=10, mid=1964, max=4080
```

映射使用参考工程的 `0..255` 输出和中心/边缘死区。四个轴都保持原始方向，Y 轴不反向。

### 肩键

肩键位于 `PA6`、`PA7`，由 ADC1 循环 DMA 采样。经过统一余量滤波后分别写入 `remote_data.left_shoulder` 和 `remote_data.right_shoulder`，肩键变化不触发蜂鸣器。

调试器可直接观察两个原始 DMA 数组：

- `remote_shoulder_adc[0..1]`：左、右肩键原始 ADC。
- `remote_axis_adc[0..3]`：右 X、右 Y、左 X、左 Y 原始 ADC。

`remote_adc_state` 为 `REMOTE_ADC_OK` 时采集正常；`REMOTE_ADC1_ERROR` 或 `REMOTE_ADC2_ERROR` 表示对应 ADC 启动 DMA 失败。

### 开关

从左到右：`PE4`、`PE3`、`PE1`、`PE0`、`PD6`、`PD5`，对应 `switch_state[0]..[5]`。

### 按键

左侧六个：`PA0`、`PC1`、`PC0`、`PA1`、`PA2`、`PA4`，对应 `key_state[0]..[5]`。

右侧六个：`PD13`、`PD12`、`PD11`、`PD8`、`PD9`、`PD10`，对应 `key_state[6]..[11]`。

### 蜂鸣器

蜂鸣器为 `PB2`，高电平导通。上电播放两次短音；任意按键或开关状态变化播放一次短音。摇杆变化不发声。

## 任务调用

启动阶段调用一次：

```c
Remote_Init();
```

遥控任务每 1 ms 调用：

```c
Remote_Update();
```

下位机通信任务后续直接读取 `remote_data`。建议通信层复制一份数据后再打包，避免发送过程中输入任务更新数组。

## 预留通信建议

当前工程不定义帧头、设备 ID、校验或发送周期。下位机协议确定后，在 `Remote.c` 中增加独立的帧结构和发送函数；`RemoteInput.c` 保持只更新 `remote_data`。临时调试用 USART1 VOFA JustFloat 帧有 8 个通道，顺序为：左肩键原始 ADC、右肩键原始 ADC、左摇杆 X/Y 原始 ADC、右摇杆 X/Y 原始 ADC、`SW_1`、`KEY_1`，不作为正式下位机协议。
